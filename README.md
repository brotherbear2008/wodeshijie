# 我的世界 · 全息投影版

说出你想要的世界，AI 设计师帮你设计人物、小零件和图稿，再投影成 3D 全息世界。不满意就接着说，一直帮你改。

## 怎么打开
- **在线版（推荐）**：用 claude.ai 上发布的链接打开。在线版的 AI 设计师由 Claude 回答，什么样的世界都能听懂；第一次用会询问是否允许（用的是你自己的 Claude 额度）。
- **本地版**：双击 `index.html`（需要联网加载 3D 引擎）。本地版用“本地设计师”，能听懂常见的说法，比如“好多好多贪吃蛇”“换成粉色”“加 5 只恐龙”。

## 四种世界
| 世界 | 玩法 |
| --- | --- |
| ⚔️ 打击空间 | 打败一波波敌人，最后有大 Boss；朋友会帮你放电，贪吃蛇召唤器会召唤全息蛇帮你咬怪 |
| 🌸 温柔空间 | 没有敌人、不会死、没有广告；摸摸小动物交朋友，收集星星，听音乐盒 |
| 🔢 高空数学闯关 | 一座座浮空岛，每座一道数独（4×4 到 9×9）或口算题，闯关送金星和金币 |
| 🐍 贪吃蛇乐园 | 很多电脑蛇一直玩，撞死了会自己复活，直到你按“不玩了”才停下来 |

## 规则
- 被打倒、蛇撞到、答错题：有 💎 复活石就直接复活；没有就要看 20~30 秒广告；👑 会员可以跳过所有广告。
- 会员 ¥1/月：跳过所有广告、死了也免广告复活、可以用所有装备。
- 装备有免费的，也有会员专属的；最多同时装 3 件。金币可以买复活石和提示灯泡。
- **这是演示版**：广告是游戏里编的模拟广告，会员只是模拟付款，不会扣真钱。设置里家长可以调广告时长。

## 改游戏
源代码在 `src/` 里，改完运行：

```bash
python3 build.py
```

会生成 `index.html`（本地版）和 `dist/artifact.html`（发布到 claude.ai 的版本）。
